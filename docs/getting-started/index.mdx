# Getting Started

`curl.md` turns noisy webpages into markdown built for agents. Start with one fetch, then decide whether you want the browser URL, the CLI, or an agent integration.

## First Fetch

Use the hosted URL directly:

```sh
$ curl curl.md/example.com
```

Or use the CLI once it is installed:

```sh
$ md example.com
```

## Narrow The Result

When you only need part of a long page, add an objective and a few keywords:

```sh
$ md docs.github.com/en/webhooks/webhook-events-and-payloads \
  --objective "pull request webhook event payload and actions" \
  --keywords pull_request
```

This keeps the output focused on the part your agent actually needs.
