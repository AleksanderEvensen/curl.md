# Pi

First-party [Pi](https://pi.dev) extension that adds `curl.md` auth commands plus `read_web_page` and `md_fetch` tool support.

## Quick Start

Install the plugin, launch Pi, and start curling.

::::steps

### Install plugin

Install the [`@curl.md/amp`](https://www.npmjs.com/package/@curl.md/pi) package with Pi:

```sh
$ pi install @curl.md/pi
```

### Start Pi

```sh
$ pi
```

### Use Pi

Now that Pi is running with the curl.md plugin, all you need to do is use Pi! Whenever Pi reads a web page, it will use curl.md.

To confirm everything is set up correctly, try this out:

```text
Read the curl.md Pi extension docs and check that we set up everything correctly
https://curl.md/docs/plugins/pi
```

::::

## Install

Install the [`@curl.md/pi`](https://www.npmjs.com/package/@curl.md/amp) npm package with Pi:

```sh
$ pi install @curl.md/pi
```

When the `@curl.md/pi` package is updated, Pi will ask if you want to update to the latest version.

## Usage

Ask for a page, paste links, or let Pi figure out what it needs to fetch.

### Prompting

Inside Pi, prompt like you normally would, for example:

```text
Read the Stripe webhook docs and extract the signing header requirements.
```

In this example, Pi will use curl.md to explore the Stripe docs while executing your prompt.

You can also tell Pi to use a specific [objective](#TODO), [keywords](#TODO), and [other options](#TODO) or let it decide what to use on its own.

### Authentication

Authenticate inside Pi with:

```text
/md_login
```

The plugin also uses the same auth model as the [CLI](/docs/guide/cli).

```sh
$ curl.md auth login
```

If you prefer non-interactive auth, set `CURLMD_API_KEY` before starting Pi.

### Status & Debugging

Use:

```text
/md_status
```

to confirm auth state, tool registration, and whether the `curl.md` CLI is available on your machine.

### Commands & Tools

After installing, Pi gets these commands:

| Command     | Description                                                                                  |
| ----------- | -------------------------------------------------------------------------------------------- |
| `md_login`  | Starts the browser-based curl.md login flow and stores the resulting session for Pi.         |
| `md_logout` | Logs out of the current curl.md session in Pi.                                               |
| `md_org`    | Switches the active curl.md account or organization Pi should use.                           |
| `md_status` | Shows curl.md auth status, registered tool info, and whether the `curl.md` CLI is installed. |

It also exposes these tools:

| Tool            | Description                                                                     |
| --------------- | ------------------------------------------------------------------------------- |
| `read_web_page` | Fetches a URL through curl.md and returns markdown optimized for coding agents. |
| `md_fetch`      | Compatibility alias for `read_web_page`.                                        |
