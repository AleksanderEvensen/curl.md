# Claude

:::important Work in progress
There is no first-party Claude integration yet. For now, use the hosted URL or the [CLI](/docs/guide/cli), and follow progress in the [GitHub repo](https://github.com/wevm/curl.md).
:::

:::tip Current workaround
Install the [CLI](/docs/guide/cli), then tell Claude to use `curl.md` or `md` to fetch and narrow web pages before continuing.
:::
