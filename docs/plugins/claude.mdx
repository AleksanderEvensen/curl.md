# Claude

`curl.md` works well as a preprocessing step for Claude when you want clean markdown instead of full webpage HTML.

## Simple Workflow

1. Fetch the page with `curl.md`.
2. Narrow it with an objective and keywords if needed.
3. Paste the markdown into Claude or attach it to your working context.

```sh
$ md docs.anthropic.com/en/docs/overview \
  --objective "tool use and response structure" \
  --keywords tools,response
```

## When This Helps

- long docs pages with lots of navigation noise
- API references where you only need one feature
- articles or changelogs you want to condense before analysis

## Status

There is no first-party Claude integration package in this repo today. For now, the recommended path is to use the hosted URL or the [CLI](/docs/guide/cli) and pass the markdown into Claude.
