# Cursor

curl.md doesn’t have a first-party Cursor plugin yet. In the meantime, we recommend adding the [curl.md skills](/docs/skills) to your agent instead.

```sh
$ npx skills add https://curl.md --agent cursor --yes
```

:::tip[Contributions welcome]
If you use Cursor and would like to contribute the curl.md Cursor plugin, check out the [Contributing Guide](/docs/dev/develop) and open a [pull request](https://github.com/wevm/curl.md).

If it meets the quality bar (please no slop) and is merged, we will give you **$100 in curl.md credits**. That’s _a lot_ of requests.
:::
