# Cursor

:::important Work in progress
There is no first-party Cursor integration yet. For now, use the [CLI](/docs/guide/cli) or [API & SDK](/docs/guide/api) alongside Cursor, and follow progress in the [GitHub repo](https://github.com/wevm/curl.md).
:::

:::tip Current workaround
Install the [CLI](/docs/guide/cli), then tell Cursor to use `curl.md` or `md` to fetch and narrow web pages before continuing.
:::
